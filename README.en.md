# ADCOS 2.0 — Connectivity OS

This repository is the source of truth for ADCOS 2.0, a ZCode-derived connectivity product for customers, providers, community networks, and connectivity applications.

Start with README.md, then read the [frozen architecture](spec/architecture/ADCOS-2.0.md), [invariants](spec/architecture/INVARIANTS.md), [dependency graph](spec/dependency-graph.md), [work orders](spec/work-orders.md), [current state](spec/development-state/current-state.json), and [Tech Lead handoff](docs/LLM-ARCHITECT-HANDOFF.md).

The target includes low-infrastructure resource contribution, authorized cross-device agent cooperation, connectivity procurement and assurance, provider Organization discovery, group purchasing, and an evidence-driven Reality Engineering Lab. These specifications do not imply those capabilities are already implemented.
